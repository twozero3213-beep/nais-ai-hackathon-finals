## 팀이 사용하는 공개 주소

[근거관문 웹사이트](https://nais-evidence-gate-finals.streamlit.app/) · [팀 로그인](https://nais-evidence-gate-finals.streamlit.app/team)

연구 데스크와 등록 근거 검산은 바로 볼 수 있다. 팀 작업실은 네 명 각자의 개인 비밀번호로 로그인한다. ADMIN과 REVIEWER 모두 과제·검토 내용을 작성하고 수정할 수 있다. 개인 접속 안내는 운영자가 별도로 전달하며 공개 저장소에 넣지 않는다. 코드 업데이트는 팀 저장소 main 반영 후 Cloud가 다시 배포한다. GitHub 저장소 쓰기 권한은 웹 로그인과 별도로 관리한다.

현재 작업실 기본 저장소는 Cloud 컨테이너의 SQLite이다. 재시작·재배포 시 보존이 보장되지 않으므로 중요한 기록은 내보내 보관한다. 외부 영구 저장소 연동은 별도 설정과 검증이 필요하다.

실제 AI 정상 사례의 저장 응답은 근거 검산의 **저장 응답 재생**에서 추가 호출 비용 없이 볼 수 있다. Cloud의 새 AI 생성에는 운영자의 서버 API 설정이 필요하다. [배포와 설정](docs/0_이영_웹배포.md), [실제 저장 응답 재생 검증](docs/0_이영_실응답재생_검증.json), [심사 피드백의 실제 반영 범위](docs/0_이영_심사피드백_반영.md)를 참고한다.
