# 원논문·원자료 검토 연결

<!-- [작성: 0 이영 · Codex] 2026-10-01 KST — 전체연동 사용자 지시와 팀 UI·승인 자료의 실제 흡수 범위 및 미완료 항목을 기록한다. 실행 시각은 연결된 JSON 영수증을 따른다. -->

연구 데스크의 **원논문·원자료 검토**에서 출처 검색 → 논문 버전·정정 관계 → 원자료 고정 버전과 이용 조건 → 허용된 CSV 수신 → 실제 바이트 SHA256 → 여섯 조건 확인 → 기존 결정적 계산 → 사람 검토 기록을 사용할 수 있다. Google Scholar는 외부 검색 링크로 원출처를 찾는다.

Cloud는 공식 HTTPS remote MCP로 Exa·Parallel·You·Tavily·Firecrawl을 호출한다. PC의 stdio 등록을 Cloud 연결 완료로 간주하지 않는다. 초기화·도구 목록·실제 호출 상태와 실패 원인을 구분한다. API 대체 경로는 명시 설정에서만 최대 한 번 사용한다. 검색 성공만으로 자료 수신·검산·승인이 완료되지 않는다.

라이선스가 분명한 공개 고정 버전의 작은 CSV만 내려받는다. 제한 자료·불명확한 라이선스·크기 초과·다른 호스트·리디렉션·코드 파일은 차단한다. 공급자 체크섬과 실제 수신 바이트 지문은 별도로 기록한다. 지정 저자 저장소의 등록 사례도 실제 파일을 다시 받은 뒤 기존 지문과 대조한다.

사람 검토는 팀 로그인·승인 역할·직접 확인·사유를 요구하며 현재 자료·논문 문맥·계산 명세·엔진을 다시 대조한다. 저장한 보고서를 불러오면 기존 사람 판단은 비활성 기록으로 보존한다. 새 검산과 사람 확인 없이 현재 승인으로 재사용하지 않는다. 일반 경로에 입력한 원문 위치·SHA는 사용자 선언이며 원논문 실제 수신의 증거가 아니다. 등록 원문은 연락처 제거 공개 사본으로 발행사 원응답 지문은 미확보다.

조지현 UI 자료의 왼쪽 탐색, 근거 연결·조건 확인·지원 계산·검토 기록, 공백 근거 차단, 조건 변경 시 확인 해제, 보조 정보 접힘과 읽기 대비를 적용했다. 올인원 문서의 합성 62%와 과거 제품 표시를 현재 실측으로 편입하지 않았다. 임도윤의 독립 배포 관측과 이채우 ZIP의 승인 보완은 작성자·시각·환경을 보존한다. ZIP 보완 코드는 원격 기준과 같아 중복 덮어쓰기 없이 새 UI에 통합했다.

[신규 실행·시험 영수증](verification/0_이영_전체연동_1차검증.json): 관련 회귀 255 통과, 화면·승인 통합 회귀 33 통과는 서로 다른 묶음이다. 실제 고정 원자료 53,098바이트·344행을 새로 수신·계산했고 사람 미승인으로 끝났다. 실제 무료 MCP 3곳 성공, Tavily 무료 한도, Firecrawl 도구 오류는 구분한다. 피드 8곳 조회 성공이며 요청 시 수집한다. 실패 시 마지막 성공 자료와 시각을 보존하지만 프로세스 재시작 후 메모리 캐시는 사라진다.

ScienceON·AIHub·NTIS 어댑터는 구현되어 있으나 현재 프로세스의 인증은 미설정이다. ScienceON은 배포 환경 등록 IP·MAC까지 확인해야 한다. AIHub 검색은 데이터 승인·다운로드와 별도다. [추가 후보 평가](0_이영_전체연동_후보평가.md)에 구현하지 않은 서비스의 공식 계약·인증·중복 이유를 기록했다.

단일 실행 식별자의 단계 재개, 논문→자료 관계 및 실제 원문 위치 보강, 명시 동의 AI 조건·다음 도구 제안은 별도 후속 구현 중이다. 전체 AI 경로 완주·모델 비교 우위·논문 전체 재현은 이번 자료의 완료 주장이 아니다. 배포 확인은 Git push 후 공개 화면의 실제 Git 식별자와 대표 동선을 대조해 기록한다.
