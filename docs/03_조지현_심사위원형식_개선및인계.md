## 1. 핵심 사용자 문제와 심사 질문
연구자는 원문 숫자를 사용할 때 어떤 자료·대상·분모·결측·방법을 확인했는지 함께 알아야 한다. 협업 중 근거가 바뀌면 예전 계산과 검토를 그대로 사용할 수 없어야 한다. 일반 AI도 계산할 수 있으므로 계산 독점성 대신 **주장·조건·근거·결과·검토의 결속과 변경 후 재사용 차단**을 증명한다.

| 세부 질문 | 현재 증거 | 상태·한계 |
|---|---|---|
| I1 기존 방식 대비 혁신 | 입력 변경 시 결과·승인 무효화, 이번 미결속 재정렬 승인 차단 | 부분 확보. 동일 자료·도구·시간의 일반 AI 비교 미실행 |
| I2 현실적 창의성·문제 해결 | 연구 지원 담당자가 수정 자료를 받은 뒤 같은 주장 검산을 다시 확인하는 흐름 | 부분 확보. 사용자 수요·절약 시간 미측정 |
| I3 AI 독창적 활용 | 실제 정상1건 조건 추출·비평2호출 공개 요약, 결정적 계산과 사람 판단 분리 | 부분 확보. 등록 조건을 모델에 제공함; 신규 논문 자동 발견·봉인 비교가 아님 |

### 발표·질의 답변에 즉시 반영할 문장
- ChatGPT로도 되나: 계산 자체는 가능하다. 차별점은 조건·근거·검토의 결속과 변경후 재사용 차단이며 일반우위는 비교 전 주장하지 않는다.
- AI 실제기여: 정상 등록1건의 조건추출·비평2호출 기록은 있다. 신규논문 자동추출·봉인비교 완주는 아직 아니다.
- 잘못 추출하면: 등록조건·원문·스키마 검사와 검산·비평으로 보류하고 사람 직접 확인을 기다린다. 모든 의미오류를 잡는다고 주장하지 않는다.
- 실제 연구자 사용: 공개자료의 제한된 주장 검토 흐름이며 조직권한·신원인증·사용성 검증이 더 필요하다.
- 본선 추가분: 이번 미결속 승인 차단·부분누락 시험·최신 상태 안내와 실제 전체검사 결과를 파일·지문·커밋으로 제시한다.
- 장애시: 확보된 실제 응답 재생·녹화가 있을 때만 대체완료로 표시한다.
- 합성사례: 규칙 시험이다. 문헌오류 확인과 제품독립재현을 구분한다.
- 확장: 스키마·계산어댑터·조건·실패시험을 함께 추가하며 동결뒤 기능 확대하지 않는다.
- 윤리: 사례편중·패배 공개,실행/미실행 투명표시,허용자료·키 비공개,직접승인·호출상한.
- 기관연계: 입력지문·원문위치·조건·계산·검토상태 보고서를 기관양식과 연결하는 후속과제. MCP/기관연계 완주를 주장하지 않는다.
