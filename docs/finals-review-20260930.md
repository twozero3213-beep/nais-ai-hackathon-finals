## 4. 제품의 중심 개념

근거관문은 **선택한 연구 주장에 원문 위치·원자료·계산 조건을 연결하고, 연결이 달라지면 결과의 재사용을 막는 연구 검산 도우미**입니다.

책임 흐름은 AI의 주장·근거 후보 제안 → 원문·자료·조건 등록 → 결정적 계산과 독립 산술 대조 → 연구자의 판단입니다. 수치 일치, 의미 연결 확인, 방법 타당성, 사람 승인, 논문 전체 재현은 서로 다른 상태입니다.

보여줄 핵심 흐름은 관심 연구 찾기 → 근거 확인하기 → 결과 가져가기입니다. 결과에는 **확인한 것 / 모르는 것 / 다음 행동**을 함께 표시합니다.

논문 검색이나 MCP 제공 자체를 최초 기능·경쟁 우위로 주장하기보다, 주장 단위의 근거·조건·결과·변경 영향을 연결하는 가치를 검증해야 한다는 것이 자료의 제품 가설입니다. 경쟁 서비스의 현재 기능과 우위는 이번 검토에서 외부 재확인하지 않았습니다.

- NTIS 최종 자료에는 실제 요청 실패와 HTTP 404, 반환 과제 0건, 실연동 성공 false가 기록되어 있습니다. 이번에 새 연결을 확인하지 않았습니다.
- 연구 worker 코드와 실제 상시 운영·예약 성공·메일 발송을 구분합니다.

최근 UI 자료의 디자인은 블루 `#1766BD`, 네이비 `#123F71`, 아이스블루 `#E9F7FF`, 보조 글자 `#4E6E93`와 노란 차단 안내입니다. 발표는 Pretendard, 화면은 IBM Plex Sans KR, 16:9, 장당 한 메시지, 실제 화면·흐름·수치를 중심으로 합니다. 7쪽 청록 발표와 5장 블루 발표는 서로 다른 제작본입니다.

최신 UI 개선에는 밑줄 메뉴, 세그먼트 선택, 검색어·저장 알림, 버튼 형태 통일, 체험 시작/다음 장면 동선과 중복 문구 정리가 있습니다. `인용 많은 순` 검색의 낮은 관련성은 인계에서 미수정 문제로 남아 있습니다.

- 5장 발표: 문제 → AI/계산/사람 역할 → 344행 정상·근거 누락·자료 변경 → 확인/미확인 → 확장 계약.
- 별도 최종 전달 폴더의 7쪽 발표도 존재합니다. 제출본을 선택할 때 두 제작본과 현재 본선 구현을 혼동하지 않습니다.
- 약 59초 영상: 메타데이터 길이 58.967초, 오디오 없음. 검색·과제 저장·3장면·고정 평가 흐름을 담고, 편집·빠른 재생을 포함한 실제 앱 조작 녹화로 설명되어 있습니다.
- 90초 영상: 길이 90초, 오디오 없음. 화면 캡처 순차 재생이며 실시간 녹화가 아니라는 표시가 있습니다.
- 두 영상 모두 실제 연구자의 업무 시간 절감 측정이 아닙니다.
- 도구 조사 문서의 조회수·별 수·제품 버전·도구 추천은 작성 당시 주장으로 보관합니다. 현재 사실이나 추천으로 사용할 때는 공식 출처를 재확인합니다. Windows 설치 프롬프트를 이번 Mac 작업에서 실행하지 않습니다.

## 10. 본선 후속 작업에 적용할 기준

1. 본선 저장소의 실제 구현·작업 시각·실행 기록을 기준으로 진행합니다. 검토 대상 자료의 성과를 본선 성과로 표시하지 않고, 가져다 쓰면 원본 지문과 실제 반영 시각을 함께 남깁니다.
2. 먼저 하나의 연구자 시나리오를 끝까지 구현하고 정상·근거 부족·자료 변경을 같은 동선에서 확인합니다.
3. AI 개입을 설명할 때 보관 제안, 실제 모델 호출, 결정적 검산, 사람 판단을 각각 표시합니다.
4. 발표 기능·수치·화면은 현재 구현과 현재 실행 증거에 맞춥니다.
5. 확장 사례는 출처·권리·버전·지문·변수·단위·분모·필터·결측·지원 방법을 채우고 성공 또는 정확한 차단으로 기록합니다.
6. 중요한 구현·수정·설계 결정은 적절한 검증 후 GitHub에 수시 반영합니다.
7. 이 검토 문서는 참고 기반입니다. 구현·코드 통합·설치·배포는 사용자의 후속 작업 범위에 맞추어 진행합니다.
