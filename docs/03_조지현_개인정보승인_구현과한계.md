# 03 조지현 · 개인정보·승인 구현과 한계

<!-- 수정 이유: 화면 안내의 미존재 문서 경로를 실제 구현 근거와 연결한다. -->
- 작성 시각: 2026-10-01T02:08:17+09:00. 이영님의 개인정보 안전장치에 조지현의 승인 입력 결속을 통합한 검토 문서다.

| 구현 | 근거 함수·동작 | 범위·한계 |
|---|---|---|
| 개인정보 형태 차단 | `finals/finals_privacy.py::sensitive_kinds`, `is_public_text`: 이메일·국내 전화번호·주민등록번호·인증 값 형태를 종류로 탐지 | 이름·소속·주소·구분 없는 번호 등 모든 개인정보를 탐지하지 못함 |
| 외부 전송 전 검사 | `finals/finals_provider.py::complete_json`: 실시간 호출 허용 확인 후 본문의 민감 형태 검사, 발견 시 연결 전에 거부 | 켜진 호출은 선택한 공개 원문 발췌와 자료 전체를 외부 모델에 전달; 이번 실호출은 미실행 |
| 후보·출력·승인 사유·보고서 검사 | `finals/finals_pipeline.py::_public_text`, `approve_report`, `export_report` | 사유에 개인정보를 쓰지 않도록 사용자가 확인해야 함 |
| 사람 직접 확인 | `approve_report`: 직접 확인 표시와 사유, 현재 자료·원문·분석 조건 지문과 재계산 검사 | 승인자 신원 인증이 아닌 사용자 확인 기록; 자동 시험 승인은 실제 사람 승인과 구분 |
| 변경 후 재사용 차단 | `_input_bindings`, `_bindings_match`, `reopen_report` | 가져온 기록은 읽기 전용; 지문은 전자서명·과학적 타당성 인증이 아님 |
| 화면 안내 | `finals_notice.NOTICE_POINTS`, `finals/app.py` | 역할 분리·사례 편중·외부 전송·보고서 저장을 사용자에게 안내 |
| 서버 로그 | `_log_run` | 검산 경로는 식별자·상태·오류 코드·소요·사용량을 기록. 후보·원문·승인 사유를 이 로그에 넣지 않음 |

공정성: 비교 입력·질문·도구·모델·시간·예산을 고정하고 미실행·실패·패배를 함께 기록한다. 등록된 8사례 결과를 모든 연구 분야의 우위로 일반화하지 않는다. 이번 보완은 로컬 합성 경계 시험이며 실제 모델 성능·실제 연구자 승인·배포 전체 완료를 의미하지 않는다.

날짜: 원출처·논문 출판·원실행·Git 이력은 보존한다. 기준 커밋보다 뒤인 팀원 주석의 작성 시각은 확인할 수 없어 '작성 시각 미확인'으로 표시하고 원표기와 실제 검토 시각은 별도 기록한다.
