# 전체 연동: 원문 근거와 효율

<!-- [작성: 0 이영 · Codex] 2026-10-01T05:27:00+09:00 — 실제 수신·원문 위치·조건 해석·계산·승인 범위를 분리하고 표시 리런 비용을 줄인다. 실행 시험 결과는 별도 영수증으로 기록한다. -->

연구 연동 화면은 검색 → 고정 논문·자료 연결 → 조건 확인 → 받은 바이트 재계산 → 사람 검토로 이어진다. Crossref·PubMed·저장소·RSS·Scholar 발견 링크와 기존 검색 MCP를 재사용한다. Cloud 연결 상태와 로컬 MCP 연결 상태는 따로 표시한다.

- 실제 JATS 바이트에서 문단의 시작·끝 위치와 문맥 SHA를 추출한다. 문서 어딘가의 문자열 존재로 위치를 대신하지 않는다. 외부 DOCTYPE 선언만 허용하며 외부 엔티티·내부 DTD·파일/네트워크 해석은 차단한다.
- 원문 여섯 조건은 사실·가설·누락으로 기록한다. 계산 전에 최대 세 해석을 봉인하며 이전 후보 집합 지문을 남긴다. 보고값에 가까운 해석을 자동 선택하지 않는다.
- AI 제안은 인용·공개 메타데이터만 한 번 전송한다. 가림 재검토는 선택한 실제 중립 문단과 열 이름만 받으며 앞선 후보값·계산·승인 기록을 제외한다. 실패에도 같은 입력의 자동 재시도는 없다.
- 다음 도구 실행은 별도 사용자 요청 한 번으로 제한한다. 원자료 레코드·파일을 사용자가 선택해야 하며, 모델이 자료를 추정하거나 승인하지 않는다. 내부 수신 바이트는 화면·감사 JSON·모델에 내보내지 않는다.
- 같은 실행의 단계 저장·재개는 실제 자료/원문/명세/엔진/사용자와 CAS를 다시 검사한다. 옛 입력·변경된 자료·늦은 응답은 유효한 결과로 재사용하지 않는다.

표시 최적화는 동일한 불변 원문 바이트의 문단 파싱 재사용, RSS 성공/실패 캐시와 arXiv 간격 재사용, 실행 지문 확인의 명시 버튼, 입력별 모델 중복 요청 차단으로 제한한다. 화면 리런은 마지막 관측을 표시하며 계산·승인·저장·재개 직전의 실제 바이트 검사는 유지한다. 새로운 라이브러리·상시 워커·전체 자료 다운로드는 추가하지 않았다.

실제 원문 관측: DOI `10.1371/journal.pone.0326678`, PMC12212921, CC BY 4.0, 244150바이트, SHA256 `f66f4426c6dc90418ab34d69773533e1d4de6e81748e30dbacaf62acb8fae9de`. 2026-10-01T04:58:05+09:00까지 안전 문단 80개와 실제 위치 5개를 확인했다. 이는 원문 수신·위치 검사이며 논문 재현·조건 의미 입증이 아니다.

국내 연결 관측: 로컬 AIHub 검색 HTTP 200·공개 결과 1건(04:50 KST). ScienceON 토큰 발급과 검색 HTTP 200(05:13 KST)이지만 검색 응답의 비공개 형태 보호가 차단하여 결과 0건이다. Cloud의 두 서비스 인증·자료 다운로드는 아직 확인하지 않았다.

검산 관측: 등록 PENG-RAW-ROWS의 실제 CSV 53098바이트와 고정 SHA를 받아 행 수 344를 대조했다. 등록 공개 사본과 발행사 원응답 바이트를 구분한다. 등록 조건·자료·원문 위치를 바꾸면 같은 숫자여도 차단한다.

한계: 정확한 인용·지문·AI 동의만으로 같은 분석군, 충분한 문맥, 논문과 자료의 인과 연결, 관측 단위의 의미를 자동 확정할 수 없다. 후보 화면의 `semantic_ready`는 항상 false이며 숫자 일치는 별도 관측이다. 새로운 논문에 대한 실제 모델 전체 흐름·실제 사람 승인·새 정상6/공격6 공정 성능 비교는 이번 구현 시험과 구분해 미완료로 남긴다. 기존 C01–C08 봉인 입력은 유지한다.
