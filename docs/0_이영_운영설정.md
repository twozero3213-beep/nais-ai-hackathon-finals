## 실시간 AI (기본값: 꺼짐)
공개 배포에서 방문자가 "실시간 AI" 버튼으로 유료 호출을 반복할 수 없도록, 운영자가 명시적으로 켠 경우에만 실행한다.

| 환경 변수 | 뜻 | 기본 |
|---|---|---|
| `OPENAI_API_KEY` | 공급자 키(값은 저장소·문서·로그에 넣지 않는다) | 없음 |
| `NAIS_ALLOW_LIVE_AI` | `1`일 때만 실호출 허용. 아니면 `LIVE_AI_NOT_ALLOWED`로 연결 전에 멈춤 | 꺼짐 |
| `NAIS_LIVE_CALL_LIMIT` | 프로세스 전체 모델 호출 수 상한(재시작하면 0부터). 넘으면 `LIVE_AI_BUDGET_EXHAUSTED` | 100 |
| `NAIS_LIVE_MAX_RUNS` | 한 화면(세션)에서 버튼을 누를 수 있는 횟수(1회 = 모델 호출 최대 2회) | 3 |
| `NAIS_SECRETS_FILE` | 선택. 이 파일의 `OPENAI_API_KEY=값` 줄만 읽는다(다른 서비스 키는 읽지 않음) | 없음 |

Streamlit Cloud에서는 Secrets(TOML)의 최상위 키가 환경 변수로 노출된다. 값은 배포 화면에서 직접 입력한다.
```toml
OPENAI_API_KEY = "(여기에 키 — 채팅·문서에 붙이지 않는다)"
NAIS_ALLOW_LIVE_AI = "1"
```
켜기 전 확인: 공급자 잔액·한도, 위 상한값. 실제 모델 응답은 아직 한 번도 성공한 적이 없다(생성 잔액 부족).

## Streamlit 설정
루트 `.streamlit/config.toml`이 실제로 적용된다(Streamlit은 실행한 폴더의 설정만 읽는다). `finals/.streamlit/config.toml`은 루트에서 실행하면 적용되지 않는다. 업로드 상한은 10MB다(웹 전체가 팀 작업실의 파일 업로드 최대 5MiB를 함께 쓰며, 검산 화면의 보고서 JSON은 256KB까지만 받는다).

## 로그
`finals.pipeline` 로거가 실행마다 한 줄 JSON(report_id·case_id·mode·state·errors·elapsed_ms·usage)을 INFO로 남긴다. 문서 원문·인용·후보 내용은 넣지 않는다. Cloud에서는 앱 로그 콘솔에서 볼 수 있다. 모듈 불러오기 실패는 `finals.app` 로거가 ERROR로 남긴다(화면에는 안내만 표시).

## 자동 시험
`.github/workflows/tests.yml`이 push·PR마다 `pytest tests finals/tests tools/test_product_metadata_guard.py`와 메타데이터 검사를 실행한다(Python 3.13, requirements.txt 고정 버전). Linux 실행은 이 PR의 첫 실행 결과로 확인한다(로컬에서는 Windows에서만 확인함).
