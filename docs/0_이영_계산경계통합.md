# 계산경계 공개 통합

계산 core 8개(typed_contracts, executor, analysis_spec, models, proposal_intake, statistics, gates, pdf_claims)와 회귀를 편입했다. 명세·방법·결측 정책의 사람 확인 guard를 유지했다. 1표본 가족 보정은 확인된 명세에 적용하고, 다중 회귀는 대상 항을 명시한다. CI/p/PDF의 척도·정밀도·신뢰수준 경계를 보존하며 99% 또는 신뢰수준 불명 CI는 REVIEW를 유지한다.

기존 공개 시험 4개와 __init__.py는 보존했다. core/team_workspace.py의 함수는 유지하며 제목만 `근거관문 · 팀 로그인`으로 수정했다. 설정 예제·getpass 스크립트·모의비밀값 시험을 편입했고 실제 secrets.toml과 비밀번호는 만들지 않았다.

## 실제 공개 사본 실행

Claude .venv Python 3.13.14 Windows에서 같은 공개 계산 집중 277건을 실행했다. 첫 실행은 **275 passed, 2 failed, 1 warning, 59.08s, exit 1**이었다. `test_case43.py::test_independent_replay_uses_bundled_public_data`와 `test_case43.py::test_system_public_cases_do_not_fake_unsupported_methods`가 `data/evaluation/cases.json` 부재로 실패했다.

자료 담당의 파일 편입 후 같은 277건 재검증은 **277 passed, 1 warning, 10.70s, exit 0**이다. 첫 실패 로그를 정정하거나 삭제하지 않았다. 경고는 의도한 fail-closed sum overflow 시험의 NumPy RuntimeWarning이다.

별도 공개 인증은 **20 passed, 21.10s, exit 0**이다. 누락 설정·잘못된 비밀번호·정상 로그인/로그아웃·역할·설정 생성 경계를 모의비밀값으로 확인했다. 실제 getpass 입력과 Cloud 사용자 로그인은 미실행이다.

공개 최소 요약은 `docs/0_이영_계산인증_공개검증.json`이다. 원출력은 로컬 운영 audit에 보존하며 Git 공개 대상과 구분한다. 공개 자료편입후 계산 원출력 SHA-256은 `c6fc726ff4c87a2a6f82c00e50c8235f15ad90123dcd45b88269f19a08fbbf65`이다. 내부 원검증 JSON·전체 로그를 공개 사본으로 복사하지 않았다.
