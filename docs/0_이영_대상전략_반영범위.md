# 대상 집중 전략의 반영 범위

‘원문과 조건을 확인하고, 근거가 바뀌면 이전 검토의 사용을 제한하며, 다음 검토자가 확인할 기록을 남긴다’는 흐름을 발표의 중심으로 삼는다. 경쟁팀에 대한 설명은 제공 자료의 소개 수준이며, 경쟁 코드·실행·공식 점수와 우위는 확인되지 않았다.

현재 확인한 것은 자료·기준 식별자·명세의 세 지문에 결속된 승인 경계, 이전 승인 무효화, 변경 설명, 보고서 저장·재열기다. 가져온 승인 기록은 읽기 전용이고 새 승인으로 활성화되지 않는다. 입력 지문 차이는 재확인이 필요한 사건이며 연구가 틀렸다는 자동 판결이 아니다.

기존 전체 시험 영수증은 **729 통과·1 건너뜀**이다. 집중 시험이나 첨부의 별도497 집계와 합산하지 않는다. 후속 코드·최종 배포의 일치는 별도 확인한다. 실제 AI는 정상 등록 사례1건에서 공급자2회 호출한 기능 실행이며 사람 승인은 PENDING이다. 등록 조건이 모델 입력에 제공됐으므로 정답 조건 비공개 추출·일반 정확도·AI 우위·시간 절감을 입증한 결과로 설명하지 않는다. 원실행은00:04대, 공개 요약 기록은00:54:49로 구분한다.

BAT 논문의 양성53명·평균 연령49.32는 [논문 원문](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0149458)에 있는 두 기술통계다. 기존 등록 검산 영수증의 두 계산과 독립 계산은 확인했으며 이번에 다시 실행하지 않았다. 이 영수증은 사람 승인·모델 호출·논문 전체 재현의 증거가 아니다. [W3C PROV](https://www.w3.org/TR/prov-overview/)가 재현·버전·절차·파생을 이미 다루므로 기록 자체의 최초성을 주장하지 않는다.

제출 전 우선 확인할 세 가지는 다음과 같다.

1. **제출본 일치:** 최종 Git 커밋·핵심 코드/자료 지문·실제 Cloud 배포를 하나의 영수증으로 대조한다. 현재 승인 경계를 중복 패치하지 않는다.
2. **실제 사람 완주:** 등록 정상 사례를 직접 검산하고 여섯 조건을 확인한 뒤 사유를 남기고 저장한다. 새 세션에서 재열어 읽기 전용 상태를 확인하고 변경 후 이전 승인 해제 장면과 저장 파일을 보존한다. 팀 로그인 성공과 자동시험은 이 완주를 대신하지 않는다. 현재 ‘자료 변경’ 버튼은 메모리 CSV 한 행 제거이며 원문 변경 버튼으로 소개하지 않는다. 같은 평균20의 A/B는 설명용 합성 반례로 구분한다.
3. **AI 범위 표시:** 현재 기능 성공을 그대로 설명한다. 조건 정답을 숨긴 새 실험이나 같은 계산 도구 비교를 수행하면 입력·평가 기준·예산을 먼저 고정하고 원출력·실패·동률도 보존한다. 실행하지 않은 비교 수치는 미측정으로 남긴다.

최소 보완 질문은 후속 후보다. 기존 오류 설명과 후보 수정은 구현돼 있지만, AI가 질문·허용 수정안을 제시해 업무를 복구하는 새 경로의 효과는 아직 검증하지 않았다. 보고값·출처 자동 수정, 자동 승인, 임의 코드 실행을 추가하지 않는다. 실제 사람 완료·공정 비교·기관 효과·비용·수상 결과는 미확정이다.
