## 2. 실제 오류 발견·수정

1. `finals/finals_pipeline.py::approve_report`, `reopen_report`: 자료와 조건이 같아도 원문이 바뀌면 승인을 재사용할 수 없도록 `_input_bindings`, `_bindings_match`로 세 입력을 대조한다. 화면 `finals/app.py`에서 세 지문을 표시한다.
2. `finals/finals_notice.py`: 안내가 공개 저장소에 없는 문서 세 개를 가리켰다. 실제 구현·한계를 설명하는 [개인정보·승인 근거](03_조지현_개인정보승인_구현과한계.md)로 연결하고 문서 존재 시험을 추가했다.
3. `finals/finals_explain.py::change_summary`: 1.00000000001과 1.0을 표시용 반올림 후 비교하면 같다고 설명했다. 독립 경계 시험 **2개가 수정 전 실패**했고, 원수치로 비교하며 표시가 겹칠 때 정밀도를 높이도록 수정한 뒤 통과했다. 이 오류는 표시 설명의 오류이며 계산 엔진 판정은 바꾸지 않았다.
4. 팀 주석의 작성 시각 19건이 그 파일이 이미 존재한 커밋보다 뒤였다. 실제 작성 시각을 확인할 수 없어 미확인으로 표시하고, 원표기와 실제 검토 시각을 [대조 기록](03_조지현_팀원변경_대조기록.json)에 분리 보존했다. 논문·실험·Git(깃, 변경 이력 관리 도구) 사건 시각을 새 작업 시각으로 덮어쓰지 않았다.
