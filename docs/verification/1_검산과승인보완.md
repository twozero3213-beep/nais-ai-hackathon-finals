- 실행 환경: Windows, Python 3.12.14

## 해결한 문제

행 대응 승인에 자료·분석 명세·기준 식별자 목록의 지문을 모두 요구한다. 누락된 지문은 `APPROVAL_UNBOUND`, 달라진 지문은 `APPROVAL_STALE`로 차단한다. 이미 순서가 맞는 입력도 제출된 승인 지문을 검사한다. 이것은 행 대응 승인의 재사용 제어이며, 논문 내용의 타당성 인증이나 승인자의 신원 인증은 아니다.

기준 목록은 정규 JSON 배열로 지문을 만든다. 줄바꿈을 포함하는 식별자가 줄 단위 연결 방식에서 서로 같은 지문으로 처리될 수 있는 문제를 해결했다. 시연은 기본으로 승인을 생성하지 않는다. 재정렬 승인은 사람이 직접 명시한 옵션과 승인자 정보가 있을 때만 전달한다.

Windows 복제에서 `evidence_gate/fixtures`의 줄바꿈이 변하면 등록된 자료 지문이 달라졌다. `.gitattributes`에 바이트 보존 규칙을 추가했다. 원자료 내용과 정답 지문은 변경하지 않았다. 팀원의 엄격한 JSON 읽기, 잘못된 명세 및 산술 오류 차단은 유지했다.

## 실제 논문과 원자료

Becker 등, *Anatomical Grading for Metabolic Activity of Brown Adipose Tissue*, 2016-02-22, DOI: 10.1371/journal.pone.0149458.

- [논문 원문](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0149458): Results / Identification of BAT positive patients의 표본 수 53, 평균 연령 49.32.
- [저자 분석 코드](https://github.com/ASBecker/BAT-Grading/blob/b02a0e302e36717b095abf9b1586a7398704f014/Brownfat.Morphology.Analysis.R#L64): `Readout.bat == 1` 조건.
- [저자 공개 원자료](https://github.com/ASBecker/BAT-Grading/blob/b02a0e302e36717b095abf9b1586a7398704f014/bat.morphology.anonymized.csv): `Age.y` 열.
- 원자료 SHA-256: `a3771cdaaecb24adedb61df55537c4c0d670456182b8e0f286e56182e3349c28`.

자료에 포함된 연구대상자의 나이는 합계 2614, 선택 행 53, 결측 0, 선택된 Study.ID 중복 0이다. 독립 십진수 계산 평균은 **49.32075471698113207547169811**이며, 논문이 소수 둘째 자리로 보고한 49.32와 허용오차 0.005 이내에서 일치했다. 이 확인은 두 기술통계의 재계산이며, 논문 전체 재현·임상 검증·논문 오류 발견은 아니다.

## 실제 실행 결과

- 실행: 2026-10-01T01:32:56+09:00 ~ 2026-10-01T01:32:58+09:00.
- `tools/1_verify_bat_paper.py`: 독립 십진수 계산, `finals` 계산 경로, `evidence_gate` 계산 경로 대조 등 **11개 항목 통과**.
- 회귀시험: **82개 통과, 1개 건너뜀**, 15.94초. A2 원자료 경로가 설정되지 않은 시험 1개는 실행하지 않았다.
- 통합 직후 첫 회귀시험은 77개 통과·4개 실패·1개 건너뜀이었다. 네 실패는 Windows 줄바꿈 변환으로 펭귄 원자료 지문이 달라진 문제였다. 바이트 보존 규칙을 추가하고 Git에 저장된 원본 바이트로 복원한 뒤 위 최종 결과를 얻었다.
- 저장 보고서 재열기는 재검토 상태를 요구했고, 보고값 변조는 무결성 오류로 차단했다. 필터 변경 사례도 차단했다. 이는 통제된 시험이며 논문에서 발견한 오류가 아니다.
- 모델 호출 0회. 실제 사람 승인 수행 없음. 조건은 사람이 등록한 것이므로 이 결과를 AI 조건 추출 성과로 계산하지 않는다.

실행 원기록은 [결과](1_bat_result.json), 실행 전 고정 조건은 [프로토콜](1_bat_protocol.json)에 있다. 결과의 기준 커밋과 코드 지문은 해당 실행 당시 작업본을 설명한다. 이후 공개 커밋의 번호로 실행 시점을 다시 쓰지 않는다.

## 다시 확인하는 방법

저장소의 의존성을 설치한 환경에서 존재하지 않는 새 출력 폴더를 지정한다. 실행 결과는 덮어쓰지 않는다.


명령줄 승인 인자는 사람이 실제 확인한 경우에만 사용한다. 이번 검증 도구는 모델 호출과 사람 승인 함수를 실행하지 않는다.
