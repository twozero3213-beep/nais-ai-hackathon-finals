# AI 윤리와 거버넌스 — 근거관문 (담당 0)

근거관문은 논문의 정량 주장을 **원문 위치·원자료·계산 조건에 묶어 결정적으로 다시 계산**하고, 자료나 조건이 바뀌면 이전 결과·승인의 재사용을 막은 뒤 **사람이 판단**하게 하는 검산 에이전트다. 윤리 설계의 중심은 "AI가 무엇을 하고 무엇을 하지 못하는가"를 코드로 나눈 것이다.

## 1. AI가 개입하는 곳과 사람이 판단하는 곳
| 단계 | 누가 | 할 수 있는 것 | 못 하는 것(코드가 막음) |
|---|---|---|---|
| 조건 후보 작성 | AI(선택, 기본 꺼짐) 또는 사람 | 원문에서 여섯 조건(방법·열·필터·분모·결측·단위) 후보를 JSON으로 제안 | 보고값·인용·허용오차를 바꿔 일치를 만들 수 없음(`REGISTERED_FIELD_MISMATCH_*`), 허용되지 않은 형식·중복 키·NaN 거부 |
| 검증·계산 | 결정적 코드 | 원문 인용·등록 조건과 대조 후 허용된 방법(행 수·평균)만 계산 | 모델 문자열 실행, 임의 코드·도구 호출 |
| 비평 | AI(선택) | 후보·원문·계산의 불일치 지적 | 승인 상태를 만들거나 근거 실패를 덮는 것 |
| 승인 | **사람만** | 원문·조건을 직접 확인했다는 체크와 사유로 승인 | AI·자동 경로의 승인, 입력이 바뀐 뒤의 기존 승인 재사용 |
| 변경 | 결정적 코드 | 자료 지문 변경 감지, 결과·승인 무효화 | 지문이 다른 결과의 재사용 |

## 2. 공식 질문별 대응 (안내문 3쪽 활용성)
| 공식 질문 | 구현한 것 | 근거 경로 · 시험 | 한계 |
|---|---|---|---|
| **투명성** | 화면에 "확인한 것 / 모르는 것"을 구분해 표기, AI를 호출하면 모델·요청 ID·토큰 수를 보고서에 남기고 호출하지 않은 것은 '미실행'으로 표시, 산술 일치를 사람 승인·논문 타당성으로 승격하지 않음, 결과표의 미실행 칸을 성공으로 채우지 않음 | `finals/finals_notice.py`, `finals_pipeline`(provider_calls 영수증), `finals/results/*/presentation-table.md` · `finals/tests/test_finals_privacy.py`, `test_finals_pipeline.py` | 비용·지연은 일부 미측정(`cost_status=NOT_MEASURED`). 모델의 내부 추론은 볼 수 없음 |
| **공정성** | 일반 AI와의 비교 입력·정답을 결과 전에 봉인(`finals/evidence/seal.json`), 두 AI 조건에 같은 입력·모델·호출/시간/출력 예산, 결과를 보고 기준을 바꾸지 않고 진 사례도 지우지 않는 규칙 | `finals/evidence/protocol.json`, `finals/comparison.py` | **AI 두 조건 16칸은 아직 실행하지 않았다**(미실행으로 표시). 현재 비교 설계는 도구 없는 모델 응답 대 검증 흐름이며 등록 조건을 모델에도 제공한다(새 논문에서 조건을 처음 발견했다는 증거가 아님) |
| **편향성** | 사례 범주를 균형으로 고정(정상 2·계산 불일치 2·근거 부족 2·자료 변경 2), 합성 3건(C03·C04·C06)을 합성으로 표기, 8개 사례로 일반 성능을 주장하지 않음 | `finals/evidence/protocol.json`, `KNOWN_LIMITATIONS.md` | 사례 8개·분야 편중(생물·임상 자료 중심)·방법 2개. 바이트만 달라도 막는 **과차단 비용**(C08). 영어 원문·한국어 화면 위주. 데이터 주체 집단별 편향 시험은 해당 없음(개인 자료를 다루지 않음) |
| **개인정보·데이터 보호** | 이메일·전화번호·주민등록번호·키 형태 차단(후보·승인 사유·보고서·외부 전송 본문), 서버에 본문 미저장, 외부 전송은 운영자가 켠 경우만·저장 요청 없음 | `finals/finals_privacy.py`, `finals_provider.complete_json`, [`docs/0_이영_개인정보점검.md`](0_이영_개인정보점검.md) | 이름·소속 같은 자유 문장은 못 잡음(화면 고지로 안내). 공급자 측 보관은 검증하지 못함 |
| **오남용 방지·안전장치** | 사람 승인 필수(명시 확인+사유+입력·제안 지문 결속), 회당 요청·시간·출력 상한, 실시간 AI 기본 꺼짐, 유료 화면의 팀 로그인·전송 동의와 선택형 운영 횟수 제한, 허용 방법 목록, 엄격 JSON, 문서 안의 지시는 데이터로만 취급 | `finals_pipeline.approve_report`, `finals_provider`(`NAIS_ALLOW_LIVE_AI`·`NAIS_LIVE_CALL_LIMIT`) | 승인자 신원 인증 없음(지문은 작성자를 인증하지 않음). 공개 읽기 화면과 유료 호출의 팀 인증을 구분한다 |
| AI를 효과적으로 구현했는가 | 제안→검증→계산→비평→승인의 경로, 실제 모델 호출은 로컬 정상 1사례(공급자 2요청, 승인 대기)의 영수증만 | `docs/0_이영_OpenAI_실행확인.json` | 서버 AI·팀 인증 연결 코드는 통합됐다. 현재 배포에서 실제 유료 호출을 이번 문서로 검증하지 않았으며, 일반 AI 대비 성능·비용은 미측정이다 |

## 3. AI 사용 공개
- **제품 안의 모델**: OpenAI `gpt-4.1-mini`(조건 후보 제안·비평, 운영자가 켠 경우에만). 전송 범위는 선택한 공개 원문 발췌와 자료 전체이며 전송 전에 개인정보·인증 값 형태를 검사한다.
- **개발 보조**: 이 저장소의 코드·문서 일부는 AI 코딩 도구(Claude Code, ChatGPT Codex)의 도움으로 작성·검토됐다. 작성·수정 이유와 검증은 `CHANGELOG.md`와 커밋 제목의 담당 번호로 추적한다. 사람의 판단이 필요한 결정(공개 범위·지출·이력)은 팀이 직접 내린다.

## 4. 위험 목록
| 위험 | 완화 | 남는 위험 |
|---|---|---|
| 모델이 원문에 없는 조건을 채운다(과잉 일반화) | 조건마다 원문 인용·위치 필수, 모르는 조건은 `null`·`unresolved`, 등록 조건과 불일치하면 보류 | 인용이 맞아도 의미가 틀릴 수 있다 → 사람 승인 |
| 수치 일치를 논문 타당성으로 오해 | 화면·보고서에 범위 문구 고정, 승인과 분리 | 발표 때 과장 |
| 자료 변경 후 옛 승인 재사용 | 지문 불일치 시 무효화, 저장 보고서는 읽기 전용으로만 열림 | 바이트 지문은 의미 변경을 판별하지 못함 |
| 공개 화면 유료 호출 남용 | 기본 꺼짐, 프로세스·화면 상한 | 운영자가 상한을 풀면 비용 발생 |
| 개인정보·키 유입 | `finals_privacy` 차단, 키는 환경 변수만 | 자유 문장의 이름·소속 |
| 사례 편중을 일반 성능으로 오인 | 8사례·합성 3건을 화면·문서에 명시 | 청중의 오해 |

## 5. 하지 않는 주장
일반 AI보다 낫다는 주장, 시간 절감·철회 예방 효과, 논문 전체 타당성 판정, 부정행위 탐지, 기관 연동·MCP·RAG가 검산 흐름에 구현돼 있다는 주장(연구 데스크의 검색·연동 기능은 별도 화면이다).
