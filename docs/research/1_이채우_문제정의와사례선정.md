## 1. 해결하려는 문제

**연구 문장의 숫자를 정확히 읽었더라도, 계산에 사용한 변수·대상·제외 조건·자료가 다르면 그 숫자를 해당 주장의 근거로 사용할 수 없다. 자료가 수정되면 어떤 주장과 사용 판단을 다시 확인해야 하는지도 알아야 한다.**

근거관문은 주장 하나를 원문 위치, 원자료 지문, 분석 조건, 계산 결과, 사람의 판단에 연결한다. 연결 근거가 부족하면 보류하고, 자료나 조건이 바뀌면 해당 결과의 재사용을 중단한 뒤 재검증하도록 설계한다.

목표 사용 장면은 공동연구자가 수정 자료를 전달한 직후다. 보고서 작성자는 수정된 표본 수와 평균을 재확인하고, 제외 기준이 불명확하면 조건 확인을 요청한다. 이는 실무 사용 가설이며 연구자 인터뷰와 업무 절감 측정은 미실행이다.

## 2. 대표 사례 A — 변수 재코딩과 분석 구문의 불일치

- 연구: *A 4-study replication of the moderating effects of greed on socioeconomic status and unethical behaviour*.
- 원논문: 2017-01-31. 정정문: 2017-09-05.
- 공식 정정문은 재코딩한 사회경제적 지위 변수를 주효과 분석 구문에 적용하지 않은 문제 등을 설명한다. 일부 계수 부호가 정정됐지만 주요 상호작용 결론은 유지됐다.
- 원출처: [원논문](https://www.nature.com/articles/sdata2016120), [정정문](https://www.nature.com/articles/sdata2017119), [정정문 보존본](https://pmc.ncbi.nlm.nih.gov/articles/PMC5584394/).

**제품 연결:** 원문이 요구한 변수와 계산에 사용한 변수를 대조해야 한다는 문제 근거다. 지정된 모형을 재계산하는 것과 올바른 변수의 의미를 판단하는 것은 다르다. 잘못 선택된 변수로도 계산 자체는 정확할 수 있다.

**검증 계획:** 제한된 회귀 재계산은 확장 후보로 둔다. 주 시연의 행 수·평균 경로가 완주한 뒤, 해당 모형의 자료·변환·보고값·허용 오차를 고정하고 실행한다. 자동으로 잘못된 변수의 의미를 판별하거나 논문 전체를 검증했다고 주장하지 않는다.

## 3. 대표 사례 B — 분석 대상과 자료 행의 대응 불일치

- 공식 공지: *Retraction and replacement of: The relationship between sexual dimorphism and androgen response element proliferation in primate genomes*.
- 공지 온라인 게재: 2023-11-24. 권호: 2024년 1월.
- 계통수의 종 표지와 분석 자료가 제대로 대응하지 않은 문제로 여러 결과와 해석이 수정됐다. 단순 철회가 아니라 철회·대체 게재이며, 공지는 부정행위를 뜻하지 않는다고 명시한다.
- 원출처: [출판사 공지](https://academic.oup.com/evolut/article/78/1/209/7440094), [서지 기록](https://pubmed.ncbi.nlm.nih.gov/37996090/).
- [저자 코드의 고정된 상태](https://github.com/AndersonDrew/Primate_ARE/blob/0217d9d103fe5829329e7abab3df08f11c6b88ac/Rwork/Supplement_3_Rework.Rmd)에는 종 표지로 자료 순서를 맞추는 구문이 있다. 링크의 커밋이 해당 구문을 처음 수정한 시점이라는 뜻은 아니다.

**제품 연결:** 고유 식별자의 중복·누락·순서 차이를 확인하고, 불일치하면 계산을 멈추는 보조 관문에 적합하다.

**검증 계획:** 합성 식별자 입력으로 정상·역순·중복·누락을 먼저 시험한다. 이 시험은 논문 원자료 재현과 별개다. 식별자 검사가 통과해도 실제 개체의 의미와 계통 통계방법 전체가 검증되는 것은 아니다. 저자 자료 재배포 조건이 확인되기 전에는 자료와 코드를 복사하지 않고 출처 링크를 제공한다.

## 4. 이번 구현 범위

| 구분 | 범위 | 완료 판정 |
| --- | --- | --- |
| 주 흐름 | 원문 조건 제안 → 확인 → 행 수·평균 계산 → 자료 변경 → 재사용 중단 → 보고서 저장 | 같은 입력의 계산·보류·변경·저장 기록을 실제 실행으로 확인 |
| 보조 관문 | 고유 식별자 대응 검사 | 정상은 통과하고 순서 차이·누락·중복은 정해진 정책대로 차단 |
| 확장 후보 | 등록된 단일 회귀 모형의 산술 검산 | 자료 접근·모형 고정·독립 기대값 대조 후 실제 결과 저장 |
| 이번 성과에서 제외 | 모든 논문 오류 탐지, 모든 철회 탐지, 자동 과학적 타당성 판정 | 별도 구현·검증 없이는 주장하지 않음 |

실제 연구 사례는 문제의 실재성을 뒷받침한다. 합성 시험은 특정 방어 규칙의 동작을 확인한다. 일반 AI와의 비교는 별도의 동일 조건 실험이다. 이 세 가지 증거를 서로 대신 사용하지 않는다.

## 5. 차별점과 남은 검증

차별점 가설은 **주장 단위로 조건·자료·계산·사람 판단을 연결하고, 변경되면 재사용을 통제하는 흐름**이다. 일반 AI도 계산과 보류를 수행할 수 있으므로 독점 기능이나 우위를 단정하지 않는다.

팀의 8사례·3조건 비교 계획을 유지한다. 같은 자료·질문·시간·허용 도구로 실행하고 실패와 동률을 포함한다. 실제 연구 사례에서 일반 AI가 실패했다고 아직 말할 수 없다.

다음 검증은 ① 숫자 형식 오류를 조용히 제외하지 않는지 ② 조건이 없으면 보류하는지 ③ 변경된 자료로 결과를 재사용하지 않는지 ④ 입력부터 보고서 저장까지 완주하는지 순서로 진행한다.
