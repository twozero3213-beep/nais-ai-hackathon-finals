# 개인정보 점검 — 근거관문 (담당 0)

점검 시각: 2026-10-01 02:2x KST · 기준 커밋 `dcd39c8` · 점검 주체: Claude(새 채팅 5). 검산 화면·저장소·로그·외부 전송 네 곳을 본다. 이 문서는 "문제가 없다"는 증명이 아니라 **무엇을 어떻게 보았고 무엇이 남았는지**의 기록이다.

## 1. 원칙
- 공개 논문·공개 자료만 입력으로 쓴다. 사용자가 입력하는 자유 문장(후보 JSON·승인 사유)에도 개인정보를 넣지 않게 화면에서 안내한다.
- 본문은 서버에 저장하지 않는다. 결과는 화면 세션에만 있고 사용자가 내려받은 보고서 파일만 남는다.
- 외부 AI 전송은 운영자가 켠 경우에만, 공개 원문 발췌와 자료만 보낸다(저장 요청 없음). 전송 직전에 개인정보·인증 값 형태를 검사한다.

## 3. 저장소 실측 (2026-10-01, 추적 파일 1,479개 중 텍스트 1,477개 읽음)
- **이메일 주소**: 실제 값 0건. 탐지된 5개 시험 파일은 가짜 값(예시·예약 도메인 example.test·example.org·example.invalid)과 SSRF 방어 시험용 URL이며, 개인정보를 제거하는 동작을 **검증**하는 시험이다.
- **주민등록번호 형태** 0건, **MAC 주소** 0건, **개인 키·토큰** 0건(시험용 가짜 키 1파일만).
- **공개 사본 정리 기록**: 논문 원문·메타데이터의 연락처를 공개 사본에서 제거했다(862개 파일·2,390개 이메일 패턴 제거, 제거 후 0개; `data/0_이영_공개사본지문.json`). 원본 입력 중 연락처가 포함된 10개 파일은 공개하지 않고 비공개 묶음으로만 보관한다.
- **남은 것 ①** 전화번호 형태 2개 파일: 논문의 교신저자 소속 주소에 실린 기관 전화번호(`data/korean_professors/pmc/fulltext/PMC13193671.xml`, `data/combined_papers_index.json`). 출판된 그대로이며 개인 휴대전화로 보이지 않지만 **제거하지 않았다** — 이 XML의 지문이 공개 사본 기록 4개 파일에 묶여 있어 지우면 지문 재등록이 필요하다. 소유자 결정 사항이다.
- **남은 것 ②** 논문 XML·지표에 실린 **저자 ORCID 1,405건(357개 파일)**과 저자 이름·소속: 공개 출판물(오픈액세스)의 메타데이터이며 이 제품은 저자 프로필을 만들거나 저자를 평가·순위화하지 않는다.

## 4. 이 점검이 하지 않은 것
- 법률 검토(개인정보 보호법 적합성) 아님. 이름·주소 같은 자유 문장의 식별 정보는 형태 검사로 잡을 수 없다.
- 배포 서버(Streamlit Cloud)의 로그 보관 기간·접근 권한, 외부 공급자(OpenAI)의 보관 정책은 확인하지 않았다(`store=false` 요청은 구현했으나 공급자 측 실제 보관을 검증하지 못했다).
- 사용자 조사·실제 연구자 자료 시험 없음.
