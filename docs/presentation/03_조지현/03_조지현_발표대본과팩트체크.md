## 1장 · 연구 수치를 다시 확인하는 근거관문 · 목표 20초

근거관문은 연구 보고서의 숫자가 어떤 원문과 자료, 분석 조건에서 나왔는지 연결하는 검증 도우미입니다. 자료가 바뀌면 이전 결과와 승인 재사용을 멈추고, 연구자가 다시 확인할 지점을 보여줍니다.

## 2장 · 실제 논문과 공개 자료의 수치 대조 · 목표 40초

공개 논문은 갈색지방 양성군 남성이 17명이라고 적었지만 저자의 공개 자료에서 같은 등록 조건으로 세면 16명입니다. 양성 대상 53명과 여성 37명은 일치합니다. 논문 본문 자체에서도 17명과 37명을 더하면 54명이 되어 보고한 대상 53명과 다릅니다. 원인은 확정하지 않았고 논문의 결론이 틀렸다는 뜻도 아닙니다. 저희가 강조하는 것은 숫자에 어떤 자료와 조건, 검토 상태가 연결되는지 남기는 것입니다.

## 3장 · 연구 프로세스와 사용자 흐름 · 목표 45초

먼저 연구자가 주장과 원문, 자료를 등록합니다. AI가 조건을 제안하거나 사람이 수동으로 작성할 수 있습니다. 계산 엔진은 허용된 방식으로 수치를 다시 계산합니다. 연구자는 원문과 분석 조건을 직접 확인하고 판단합니다. 마지막으로 결과와 근거를 보고서로 저장하고 다시 엽니다. 근거 부족은 보류하고 자료 변경은 재확인합니다.

## 4장 · AI 구성과 데이터 활용 · 목표 45초

외부 OpenAI API는 제한된 입력에서 조건 후보를 반환합니다. 로컬 엔진이 형식과 원문 연결, 등록 조건을 대조하고 행 수와 평균을 재계산합니다. 결과가 같아도 최종 사람 승인은 별도입니다. 정상 사례 한 건의 실제 조건 추출 기록이 있으며 사람 승인은 대기입니다. 새 실제 AI 제안과 비평 두 단계의 완주나 일반 AI 대비 성능은 아직 확인하지 않았습니다. 로컬 자료와 파일 보고서, 별도 팀 작업실 저장소를 구분합니다.

## 5장 · 구현된 UI와 사용자 시연 · 목표 65초

실제 로컬 브라우저 화면입니다. 메인에서 등록 사례와 후보 작성 방법을 선택합니다. BAT 사례는 53명의 평균 연령을 검산해 보고값 49.32세와 허용오차 내에서 일치했습니다. 이 시연은 수동 작성 경로입니다. 보고서를 내려받아 다시 열고 현재 입력과 연결되는지 확인합니다. 같은 녹화에서 한 행을 제거한 뒤 이전 결과 사용이 멈추는 것도 확인했습니다. 사람 승인 완료나 실제 AI 실행으로 설명하지 않습니다.

## 6장 · 8개 봉인 사례의 실제 로컬 결과 · 목표 50초

정상 두 건, 계산 불일치 두 건, 근거 부족 두 건, 자료 변경 두 건을 사전에 등록했습니다. LLM 없는 로컬 경로에서 여덟 판정이 등록 기준과 일치했습니다. 정상 수치는 확인하고 불일치는 설명하며, 근거 부족과 자료 변경은 보류합니다. 일부는 합성 규칙 또는 통제 변형입니다. 이 8분의 8은 일반 정확도가 아니며, 두 AI 조건의 열여섯 비교 관측은 미실행입니다.

현재 확보한 것은 등록 사례의 근거 검산과 보고서 저장, 변경 차단입니다. 다음으로 동일 조건의 AI 비교를 수행하고, 후속으로 다른 분야와 연구실, 실증허브에서 업무 시간과 오류 비용을 측정하겠습니다. 통계 방법과 기관 데이터 연결은 이 검증을 거쳐 확대합니다. 자료가 바뀌면 결론도 다시 확인해야 합니다.
