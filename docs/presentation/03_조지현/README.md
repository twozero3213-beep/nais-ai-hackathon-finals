## 사실과 실행의 경계

- 논문 남성 17명과 공개 자료 16명은 출판사 본문과 같은 지문 자료를 재대조했습니다. 원인은 미확정이며 논문 결론 오류를 뜻하지 않습니다.
- 8/8은 사전 등록 기대 판정과 일치한 8사례입니다. 일반 정확도가 아니며 AI 비교 16건은 미실행입니다.
- 실제 AI 정상 1건, 화면에서 보여준 수동 검산, 저장 응답 재생, 사람 승인을 구분합니다. 원실행 시각을 이번 작성 시각으로 바꾸지 않았습니다.
- 첨부 원본의 회귀 시험 증가 그래프·Claude 수행 문장·배포본 승인 완료 기록은 통합 발표 본문에서 생략했습니다.
- PDF 화면은 고정되어 글자 검색·선택이 되지 않습니다. 편집용 PPT의 글꼴 파일 자체는 포함되지 않으므로 발표에는 PDF를 사용합니다.
- 최신 근거 경계 검증의 수치·승인 보완은 남아 있습니다. 등록 8사례 결과를 모든 입력의 안전성으로 확대하지 않습니다.
- 실제 발표 리허설 시간은 미측정입니다. 새 유료 모델 호출·제품 회귀·외부 성능 비교는 실행하지 않았습니다.
