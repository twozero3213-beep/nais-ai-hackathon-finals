# 본선 공개자료와 지문 검증

<!-- [수정: 0 이영 · Codex] 공개 자료 경로와 원본/공개 SHA를 연결한다. 원 작업 기록은 로컬 원기록 SHA로 봉인한다. -->

공개 사본의 연락처 파일 862개에서 개인 이메일을 제거했다. XML 854개는 DOI/PMID·본문 문단·표셀, CSV 1개는 모든 행과 비연락처 셀, JSON 2개는 숫자필드가 동일하다. R 1개는 주석의 연락처만 제거했고 비주석 실행줄이 동일하다. R 코드는 실행하지 않았다. 원본 ZIP과 원자료 작업트리는 보존했다.

원본과 공개 사본의 지문은 [공개사본지문](../data/0_이영_공개사본지문.json)에 분리하여 기록했다. 운영 참조 19개와 관련 파일 881개의 현재 공개 SHA가 일치한다. 기존 모델 실행 영수증의 원본 지문은 유지하며 공개 자료 정리가 논문 재현·모델 실행·사람 승인을 의미하지 않는다.

현재 공개 코드의 추출기 case69.1로 코퍼스를 재구축하고 검증했다. 644개 원문 97,981,010바이트를 hash 검사했으며 900편, 본문 644편, 서지 256편, 단락 50,091개, 표후보 29,501개, 파싱실패 0개로 PASS했다. 봉인된 팀 메타데이터 지문은 유지했다. 원본 manifest와 공개 manifest는 서로 다른 지문으로 기록한다.

현재 공개 경로의 tests/test_case68.py, tests/test_case69.py, tests/test_case105_team_corpus.py를 실제 실행하여 36 passed(2.81초)를 확인했다. 외부 Data.gov API 주소·표시·허용 경계는 mock 시험 5 passed(0.44초)로 확인했다. 실제 외부 API 호출은 이 검증 범위에 포함되지 않는다. static 공개 catalog/examples/OpenAPI 형식과 지문도 PASS했다.

선행 공개자료 정리에서 data 이메일 패턴 발견 파일은 0개였다. PDF 2개·6페이지의 텍스트·메타데이터·주석 및 원시 바이트에서도 이메일 패턴 0개를 확인했다. 이미지의 OCR은 수행하지 않았으며 PDF 바이트는 수정하지 않았다.

편입 기록은 [첫 편입](intake/0_이영_case105_import_manifest.json)과 [추가 편입](intake/0_이영_case105_import_manifest_2.json)에 있다. 현재 공개 경로와 실제 SHA/bytes만 표시하고 원 자료 경로는 source_path_sha256으로 봉인했다. 원래 파일명·자료 작성 시각을 다른 값으로 바꾸지 않았다. [조립 기록](0_이영_공개사본조립.json)이 원격 기준 커밋, 현재 코드 지문과 공개 사본 파일목록을 연결한다.
