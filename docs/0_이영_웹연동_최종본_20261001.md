검색·원논문·원자료·파일 지문·조건 후보·결정적 계산·사람 검토 화면을 기존 사이트에 연결했다. 기존 연구 데스크·팀 작업실·검산 흐름은 유지한다. 반복 화면에서는 불변 원문 파싱과 마지막 관측을 재사용하며 계산·승인·저장 직전 입력 및 엔진 검사는 유지한다.

- 최종 통합 실행: 943 통과/1 실패, 571.28초. 실패 원인은 시험에서 사람 검토 단계 이동 누락이며 수정 후 단독 1 통과/24.37초. 전체 재실행 완료로 바꾸어 쓰지 않는다.
- 별도 UI 묶음: 46 통과/1 실패. 바뀐 제목과 단계 이동을 반영한 해당 시험 1 통과/31.17초.
- 최신 수치·승인 정규화·실행 지문 통합: 83 통과/31.13초. 원격 팀 수치 및 승인 패치를 모두 포함한 별도 실행이다.
- 공개 추적 1734파일 위생 검사 0건, 메타데이터 150 JSON 통과. 이는 앱 성능이나 과학적 재현 점수가 아니다.
- 로컬 실호출: ScienceON 공개 검색 1건, AIHub 공개 검색 1건, JATS 실제 문단 위치·지문 확인. Cloud의 국내 서비스 인증·새 실제 AI 전체 흐름·새 논문 의미 연결·실제 사람 승인은 미확인 또는 미완료이다.

Git 반영과 Cloud 화면 관측은 별도로 공용 최종 기록에 남긴다. 새 원문 조건의 의미를 숫자 일치만으로 확정하거나 모델 응답을 사람 승인으로 바꾸지 않는다. 3분 자동 업데이트는 최종본 확정을 위해 일시 중지했다.
