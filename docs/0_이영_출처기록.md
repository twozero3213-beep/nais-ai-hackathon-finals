## 4. 저장소 이력에 대해 (사실만)
- 공식 저장소 main의 이력은 본선 중 **두 번 교체**됐다. ① 2026-09-30 23:09 KST 이전 27개 커밋과 시작 태그를 제거하고 부모 없는 새 루트로 교체(소유자 직접 지시). ② 2026-10-01 00:42:42 KST 강제 갱신(로컬 `git reflog`의 forced-update 기록). 복구용 이전 이력은 로컬에만 있다.
- 교체 뒤 main의 첫 커밋은 `7a8ceae`(23:05)이며 기준 커밋 시점에 34개 커밋, 작성자는 이영 26·이채우 6·조지현 1·소유자 계정 1이다. 커밋 제목의 담당 번호(`[0 이영]`·`[1 …]`·`[3 조지현]`)로 담당을 구분한다. **커밋 시각은 그 파일 전체의 작성 시각이 아니다**: 23:05·23:21 커밋은 본선 이전 자료에서 온 대량 편입을 포함한다.
- 교체 전 이력의 일부는 GitHub 서버에 주소로 남아 있을 수 있다. 이채우의 00:01~00:02 커밋이 추가한 문서 2개(`docs/intake/1-review-…`, `1-source-audit-…`)는 교체 뒤 main에 없다(커밋 객체는 로컬 보관).
