## 발표에서 지킬 범위

산술·멈춤 통과와 원문 의미 검증을 구분합니다. 정확한 인용이 있다는 사실은 그 인용의 해석이 맞다는 증명이 아닙니다. 현재 봉인 사례의 수동 등록 조건이 모델 입력에 포함돼 있으므로 수동 매핑 감소율을 주장할 수 없습니다. 원문 조건이 부족해 우리 경로가 차단되는 사례와 일반 AI가 통과하는 사례도 결과표에 그대로 남깁니다.

사전에 고정한 자료 변경 사례는 유효한 비교 입력입니다. 실행 도중 파일이 바뀌는 상황은 비교 무효입니다. C07(행 제거)·C08(줄끝 변경)의 사전 등록 변화가 도중 변경과 혼동되지 않는 경계 시험도 통과했습니다. 새 합성 시험 사본은 시험용이며 원래 봉인 사례를 대체하지 않습니다.

실제16칸 AI 비교·요금 영수증·최신 배포 코드 확인과 전체 시연은 미실행 또는 미확인입니다. 이번 단계는 검증 가능한 비교 실행기 보완까지입니다. 이 기록 작성 시점의 업로드 상태는 대기이며, 실제 원격 확인은 후속 영수증으로 남깁니다.
